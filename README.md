# Check-Your-Git
Have Ever Checked your Git Repo.

# Help Menu
```bash
wget https://raw.githubusercontent.com/0xmrsecurity/Check-Your-Git/refs/heads/main/CheckMyGit.sh
chmod +x CheckMyGit.sh

===>  bash CheckMyGit.sh --help
===>  bash CheckMyGit.sh -u <Url>
===>  bash CheckMyGit.sh -p <Path>
```

# Feature 
- SSL Support
- Authors Detection
- Object listing/Files
- Secrets Detection
- Regex fingerprint check
- Commit History
- List all Branches 
- Tags Extraction
- TruffleHog  Detection 
- gitleaks    Detection
